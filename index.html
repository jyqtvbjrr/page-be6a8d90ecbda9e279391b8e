02 / 客户端接入与同步步骤

CLIENT SETUP INSTRUCTIONS

桌面平台 (Windows / macOS)

  1. 获取个人中心生成的订阅 URL。
  2. 在对应客户端中新建订阅并粘贴完整链接。
  3. 执行节点解析，更新本地缓存文件。
  4. 在策略组中选取延迟最低的可用接入点。

移动设备 (iOS / Android)

  1. 使用支持全协议配置文件的移动端工具。
  2. 通过扫描二维码或长按导入配置文本。
  3. 启用系统网络权限并验证本地路由回路。
  4. 分流规则建议选用规则模式而非全局模式。

路由及网关设备

  1. 下载由网抑云后台导出的 YAML 或 JSON 格式原始配置。
  2. 上传至网关系统指定配置存储路径。
  3. 设定定时重启 Cron 任务以按周期拉取新节点池。
  4. 监控并发请求数量，避免超出套餐设备上限。

03 / 常见技术与计费问题

FREQUENTLY ASKED QUESTIONS
#01

设备同时在线数是如何计算的？

系统按当前正在建立长连接通信的独立 IP 与设备标识符进行统计。若基础版超出 3 台设备、旗舰版超出 5 台设备或团队版超出 20 台设备，后接入的终端将收到网络握手中断限制，直至旧连接释放。

#02

每月配额流量重置周期如何计算？

流量并非自然月 1 号统一清零，而是根据订单首次激活日期的对应时间戳每 30 天自动重置一次。当月未使用完毕的剩余流量不支持累加至下个账期。

#03

流媒体解锁与普通节点池有何区别？

基础版配备的普通线路节点池适用于常规网页浏览及基础流媒体；旗舰版及团队版包含的原生流媒体解锁线路针对区域性版权库提供定制出口标识，支持更高码率的视频流传输。

#04

订阅链接拉取失败应排查哪些环节？

首先核对本地客户端是否启用了系统代理干扰订阅请求；其次确认本地 DNS 是否正确解析订阅域名；若仍无法更新，请登录网抑云控制台手动复制单节点节点代码导入测试。
